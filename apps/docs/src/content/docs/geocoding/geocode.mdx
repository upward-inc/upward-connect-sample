リクエストボディで指定された住所リストを経緯度形式に返却する

## 📬 リクエスト

`POST https://engine-prod-je-apim.azure-api.net/connect/api/v1/geocode`

### リクエストヘッダ

| キー | 値 |
| --- | --- |
| Content-Type | `application/json` |
| X-API-Key | 認証用のAPIキー |

### リクエストボディ

<RequestBodyTable>
  <RequestBodyTableRow name="requests" type={`<a href="#requestオブジェクト">requestオブジェクト</a>の配列`} required={true} example='[ { "id": "A001", "address": "東京都千代田区丸の内１丁目４−１" }, ... ]'>
    ジオコーディングの住所リスト（最大100件まで）
  </RequestBodyTableRow>
</RequestBodyTable>

#### requestオブジェクト

<RequestBodyTable>
  <RequestBodyTableRow name="id" type="文字列" required={true} example='A001'>
    今回のリクエスト内でユニークなリクエストID（最大255文字）
  </RequestBodyTableRow>
  <RequestBodyTableRow name="address" type="文字列" required={true} example='東京都千代田区丸の内１丁目４−１'>
    ジオコーディングする住所（最大512文字）
  </RequestBodyTableRow>
</RequestBodyTable>

```json title="リクエストボディのサンプル"
{
  "requests": [
    {
      "id": "A001",
      "address": "東京都千代田区丸の内１丁目４−１"
    },
    {
      "id": "A002",
      "address": "間違った住所サンプル"
    }
  ]
}
```

## 💥 失敗レスポンス

| HTTPコード | 原因 |
| --- | --- |
| `400`: Bad Request | 不正のリクエストボディ / 「id」の重複 / 100件以上のリクエストを指定 |
| `401`: Unauthorized | リクエストヘッダに「X-API-Key」の値がない / 不正な「X-API-Key」の値 |
| `429`: Too Many Requests | リクエストが短時間に大量に送信された場合など、一定のレート制限を超過した（レスポンスヘッダの「Retry-After」に待機秒数を設定するので、指定秒数経過後に再送してください） |

## 💬 具体的な要求事項

- すべての文字はUTF-8でエンコードしてください
- リクエストの配列順序とレスポンスの配列順序は一致しません。必ず、「id」フィールドを用いた突き合わせを行ってください
- すべてのリクエストがジオコーディングできない場合も成功レスポンスとして「`200` : OK」を返却しますのでご注意ください
- ジオコーディング精度向上にあたっては、[マッチングレベルの向上施策](https://navi.upward.jp/documentation/setup/setup-salesforce-platform/geocoding/matching-level/)も合わせてご確認ください
