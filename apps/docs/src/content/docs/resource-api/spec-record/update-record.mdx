## 📬 リクエスト

<code>PATCH \{resource_api_url\}/records/\{entity_name\}/\{id\}</code>

### リクエストヘッダ

| キー | 値 |
| --- | --- |
| Authorization | `Bearer {アクセストークン}` |
| Content-Type | `application/json` |

## 💬 具体的な要求事項

### 基本要求

- 指定されたエンティティ名・レコードIDとフィールドの値を元にレコードを更新してください
- 更新対象のレコードが存在しない場合は、「`404` : Not Found」エラーを返却してください

### その他（補足等）

- UPWARDから送信されるリクエストボディには、「is_updatable」フィールドが`true`の項目のみ含まれます（`false`の項目についてはサポートする必要はありません）
- 必要に応じて、貴社が定める仕様に基づいてリクエストボディのバリデーションを行ってください
