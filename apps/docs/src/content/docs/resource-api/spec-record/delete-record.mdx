パスで指定されたエンティティのレコードを削除する

## 📬 リクエスト

<code>DELETE \{resource_api_url\}/records/\{entity_name\}/\{id\}</code>

### リクエストヘッダ

| キー | 値 |
| --- | --- |
| Authorization | `Bearer {アクセストークン}` |

### パスパラメータ

<ParameterTable>
  <ParameterTableRow name="entity_name" type="文字列" required={true} example="account">
    削除対象レコードのエンティティ名
  </ParameterTableRow>
  <ParameterTableRow name="id" type="文字列" required={true} example="account-00000001">
    削除対象のレコードID
  </ParameterTableRow>
</ParameterTable>
