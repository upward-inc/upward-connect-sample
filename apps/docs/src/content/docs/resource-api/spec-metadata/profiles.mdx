プロファイルの情報を一覧で返却する

## 📬 リクエスト

<code>GET \{resource_api_url\}/profiles</code>

### リクエストヘッダ

| キー | 値 |
| --- | --- |
| Authorization | `Bearer {アクセストークン}` |

### パスパラメータ

なし

### クエリパラメータ

なし

## ✨ 成功レスポンス

### ステータスコード

`200` : OK

### レスポンスヘッダ

| キー | 値 |
| --- | --- |
| Content-Type | `application/json` |

### レスポンスボディ

[単一プロファイルの取得 - レスポンスボディ](/resource-api/spec-metadata/profile#レスポンスボディ)と同内容の配列

#### レスポンスボディのサンプル

```json title="レスポンスボディのサンプル"
[
  {
    "name": "admin",
    "display_name": "システム管理者"
  },
  {
    "name": "standard_user",
    "display_name": "一般ユーザー"
  },
  ...
]
```

## 💬 具体的な要求事項

- 配列のソート順は任意ですが、冪等になるようルールを設定してください
