パスで指定された単一のエンティティ項目情報を返却する

## 📬 リクエスト

<code>GET \{resource_api_url\}/entities/\{entity_name\}/items/\{name\}</code>

### リクエストヘッダ

| キー | 値 |
| --- | --- |
| Authorization | `Bearer {アクセストークン}` |

## 💬 具体的な要求事項

- 検索対象のエンティティ項目名が存在しない場合は、「`404` : Not Found」エラーを返却してください
- 「sub_type」フィールド : `combobox`
  - 任意のテキスト入力を受け付けながら、選択肢による入力補助機能を利用するフィールドの場合に`combobox` を設定します
  - 「options」フィールドに対しての選択肢一覧の設定も必要になります（[comboboxフィールドの挙動サンプル](/combobox.mp4)）
- 「is_formula」フィールド
  - このフィールドの値が `true` である場合（計算によって表現されるフィールドである場合）、以下のフィールドと値の組み合わせを設定してください
    - is_required: `false`
    - is_filterable: `true`
    - is_creatable: `false`
    - is_updatable: `false`
