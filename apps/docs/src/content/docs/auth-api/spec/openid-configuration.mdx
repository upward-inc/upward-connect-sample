OIDC 1.0で定められた OpenID プロバイダーに関する情報を返却する

## 📬 リクエスト

<code>GET \{auth_api_url\}/.well-known/openid-configuration</code>

### リクエストヘッダ

なし

### パスパラメータ

なし

### クエリパラメータ

なし

## ✨ 成功レスポンス

### ステータスコード

`200` : OK

### レスポンスヘッダ

| キー | 値 |
| --- | --- |
| Content-Type | `application/json` |

## 💬 具体的な要求事項

### 基本要求

- OIDC 1.0プロバイダー構成エンドポイントの仕様に従い実装してください

### その他（補足等）

- OpenID Provider Metadataで列挙されたオプションのうち、[レスポンスボディ](#レスポンスボディ)に記載されてないフィールドについては、UPWARDから参照しないためサポートする必要はありません
